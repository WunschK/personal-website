Designing and implementing the design system for Europäische Religionsfrieden Digital.

## Project Overview

EuReD (Europäische Religionsfrieden Digital) is a digital edition of European religious peace agreements. I was responsible for the entire design system and front-end implementation.

## Challenges

- **Historical Material**: Present centuries-old texts in a modern interface
- **Multilingual**: Support German, Latin, and other languages
- **Accessibility**: Ensure scholars of all abilities can use the resource
- **Responsive**: Work across devices from phones to large research displays

## Design Decisions

- Clean typography for long-form reading
- Flexible grid system for complex layout needs
- Color system respecting historical aesthetics
- Progressive enhancement for older browsers

## Technical Stack

- Semantic HTML5
- Modern CSS (Grid, Flexbox, Custom Properties)
- Minimal JavaScript for enhancements
- Focus on performance and accessibility

## Outcomes

The site successfully serves researchers worldwide, with positive feedback on usability and design.
